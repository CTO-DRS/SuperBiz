# scripts/ — أدوات دمج النصوص التاريخية

> [تدقيق L-8 — توثيق] هذه برامج دمج لمرة واحدة استُخدمت في موجات P11–P18
> لدمج أجزاء النصوص (`pN_strings/N-a.txt` + `N-b.txt`) في
> `app/src/main/res/values*/strings.xml`.

- **برامج P13–P18 موجودة** — مُصلَحة المسارات (كانت بمسار مطلق لجهاز التطوير،
  الآن نسبي لمجلد المستودع عبر `__file__`).
- **برامج P11 وP12 غير موجودة عمداً** — أجزاؤها (`p11_strings/` و`p12_strings/`)
  مدموجة بالفعل في strings.xml منذ موجاتها، والبرنامجان ضاعا مع إعادة بناء
  المستودع لإصدار V 1.0.0. إعادة كتابتها لا قيمة لها — الأجزاء مرجع تاريخي فقط.
- **تشغيل أي برنامج اليوم لن يضيف شيئاً** (الأجزاء مدموجة) — تُستخدم فقط
  كمرجع لفهم كيفية وصول النصوص الحالية.

القاعدة الثابتة: أي إضافة نصوص جديدة تُضاف مباشرة إلى الملفين (ar/en) معاً
والفاحص الآلي في CI يفرض توازن المفاتيح.
