# SuperBiz Web Console — بوابة الويب

> **المسار W1** من خارطة الطريق الذكية المتكاملة ([`docs/ROADMAP_SMART_2026.md`](../docs/ROADMAP_SMART_2026.md)) — نسخة ويب v0.1 للمعاينة الحية، مطابقة لهوية التطبيق (RTL · ثيم Glass: نافي `#0B1026` · بنفسجي `#8B5CF6` · سماوي `#22D3EE`).

**هذه بوابة مستقلة تمامًا عن تطبيق الأندرويد** — لا تلمس التزام «دون اتصال 100%» ولا قائمة الخروج المغلقة (ADR-001 D5)، فهي Artifact منفصل بعقد خاص. عند الربط بالمزامنة مستقبلًا (W3) سيتم عبر ADR-003 قبل أي كود شبكي.

## العقود الموروثة من التطبيق (غير قابلة للتفاوض)

- **المال قروش (Int)** — صفر Double في أي مسار مالي؛ العرض ريال بمنزلتين.
- **القيد المزدوج متوازن إلزاميًا** — `postJournal` يرفض أي مسودة `debit != credit` قبل الحفظ (مرآة `AccountingEngine.kt`).
- **الذرّية** — كل عملية متعددة الجداول داخل `db.$transaction` واحدة.
- **الترقيم التسلسلي من قاعدة البيانات داخل المعاملة** + زاتكا: UUID/ICV لكل فاتورة.
- **ZATCA صارم لـSA** — ضريبة 15% افتراضيًا، QR مرحلة-1 فقط في v0.1.

## التشغيل

```bash
cd web
bun install                 # أو npm install
cp .env.example .env        # DATABASE_URL + كلمة مرور المالك (انظر المصادقة أدناه)
bun run db:push             # إنشاء الجداول
bun run dev                 # http://localhost:3000
```

البذر التلقائي: أول استدعاء لأي API يزرع بيانات تجريبية حتمية (12 منتجًا، 6 أطراف، ~53 فاتورة موزعة على 30 يومًا، سدود جزئية، مصروفات) — **لا مخزون سالب أبدًا** والتوازن المحاسبي تام — **ويحدث حصراً بعد جلسة صالحة** (الطلبات المجهولة تُمنع قبل لمس القاعدة).

## المصادقة (موجة W1.5 — Issue #39 · قرار ADR-004)

البوابة **مقفولة افتراضيًا (G5)**: كل مسارات الكتابة والقراءات المالية خلف جلسة مالك، والقراءة العامة الوحيدة `GET /api/roadmap`.

```bash
# في web/.env — بلا هذا السطر: البوابة مغلقة كلها (الدخول يعيد 503 AUTH_NOT_CONFIGURED)
SUPERBIZ_OWNER_PASSWORD="pin-قوي-جداً"     # أو SUPERBIZ_OWNER_PASSWORD_HASH بصمة PBKDF2 جاهزة
SUPERBIZ_SESSION_SECRET="سر-عشوائي-طويل"  # اختياري — يُشتق من الاعتماد إن تُرك فارغاً
```

- **الدخول:** `/login` (ثيم Glass الماركة) — جلسة HMAC-SHA256 لمدة 12 ساعة بكوكة `httpOnly + SameSite=Strict + Secure` في الإنتاج.
- **الأقفال الثلاثة على كل كتابة:** حد معدل (429) ← فحص CSRF بـOrigin (403) ← الجلسة (401) — في `src/proxy.ts` مركزياً، **مع حرس ثانٍ** `requireSession` داخل كل handler كتابة.
- **حد المعدل:** دخول 5 محاولات/5 دقائق لكل IP (تشمل الناجحة) · كتابة 120/دقيقة.
- **فاحص CI:** `bun run check:auth` — أي handler كتابة جديد بلا بوابة = أحمر يكسر CI.
- **تفاصيل القرار والبدائل المرفوضة والعواقب:** [`docs/ADR-004_WEB_AUTH.md`](../docs/ADR-004_WEB_AUTH.md).

## حلقة الجودة (موجة W1.4 — Issue #38 · موسَّعة W1.5/#39 · W1.6/#40 · W1.7 — Issue #41)

```bash
bun install --frozen-lockfile   # تثبيت قابل للتكرار — bun.lock متزامن إجبارياً (CI مجمد)
bun run test           # جناح العقود + المصادقة (vitest — 42 اختبارًا نقياً، نمط G7)
bun run check:auth     # فاحص بوابة المصادقة — أي handler كتابة بلا requireSession = أحمر
bun run check:deps     # فاحص الاعتماديات [W1.6] — أي حزمة إنتاج بلا استيراد = أحمر
bun run typecheck      # tsc --noEmit — مفروض: next.config لا يخفي أخطاء الأنواع (ignoreBuildErrors: false)
bun run lint           # eslint — نظيف إجباري
DATABASE_URL="file:./ci-check.db" bun run build   # بناء إنتاج كامل بأنواع مفروضة
```

- **الناقلات الذهبية المُرحَّلة حرفيًا من `ZatcaQrTest.kt`** (عينة Bunnia المرجعية + حدود TLV + طابع 20 بايت) تضمن تطابق بايتي بين محرك الويب ومحرك الأندرويد — أي انحراف مستقبلي = أحمر في الجهتين.
- **القيد المزدوج مختبر نقيًا:** مسودة غير متوازنة بفرق قروش واحد تُرفض بلا أي كتابة.
- **اختبارات التكامل [W1.7]:** معالجات المسارات الحقيقية فوق SQLite ملفية (`globalSetup` يهيئها مرة واحدة) — 24 اختبار مسار + خاصيتا «كل قيد متوازن مساواةً تامة» و«لا مخزون سالب أبدًا» على كل ما في القاعدة.
- **تحقق zod موحد [W1.7]:** كل مسارات الكتابة خلف `src/lib/schemas.ts` — رفض 400 `{error, code:"INVALID_INPUT"}` برسائل عربية؛ المال قروش Int حصراً في السدود (G2)، وأسعار المنتجات ريال يدخل/قروش يُخزَّن.
- **تقليم الاعتماديات [W1.6]:** 21 حزمة إنتاج ميتة أُزيلت — كل حزمة معلنة إما مستوردة فعلاً أو موثقة بقائمة سماح (`react-dom` إطاري، `prisma` CLI) — والفاحص `check:deps` يمنع رجوع أي حزمة ميتة.
- تقرير الفحص المولِّد لهذه الحلقة: [`docs/INSPECTION_REPORT_W1_WEB.md`](../docs/INSPECTION_REPORT_W1_WEB.md) — وCI يشغّل الحلقة كاملة على كل تعديل `web/**` (`.github/workflows/web.yml`).
