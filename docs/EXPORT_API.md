# مواصفات التصدير العامة — SuperBiz Public Export API (v1)

> **[H5-4 V 3.2.0]** هذا المستند هو العقد العام لملفات التصدير القياسية.
> مصدر الحقيقة الآلي: `app/src/main/java/com/superbiz/app/export/ExportSchemas.kt`
> (اختبار الحارس: `ExportSchemasTest` — أي انحراف بين هذا المستند والكود يكسر CI).

## القواعد العامة (كل الملفات)

| البند | العقد |
|---|---|
| الترميز | UTF-8 مع BOM (يفتح مباشرة في Excel بأي لغة) |
| أسماء الملفات | `superbiz-<entity>-<yyyyMMdd-HHmmss>.xlsx/.csv` |
| الفاصل CSV | `,` مع اقتباس RFC (تضاعف `"` الداخلية) + CRLF |
| حرس حقن الصيغ | أي حقل نصي يبدأ بـ `=` أو `+` أو `@` أو Tab/CR يُسبق بعلامة `'` (عقد H-21 في `CsvKit.escape`؛ `-` مقصوداً مستثنى لتبقى الأرقام السالبة رقمية) |
| خلايا XLSX | `inlineStr` نصية أو رقمية فقط — لا صيغ إطلاقاً فلا متجه حقن |
| وحدات المال | الأعمدة ذات النوع `MONEY_RIYAL` خلايا **رقمية بالعملة الأساسية** (ريال عائم 2-عشري) — القروش الداخلية تُحوَّل عند حدود التصدير حصراً (`Money.fromPiasters`) |
| التوطين | الرؤوس تُحل من الموارد بلغة الواجهة لحظة التصدير؛ **المستورد الآلي يربط بترتيب الأعمدة وعددها (العقد الثابت) لا بالملصقات** |
| الإصدار | `ExportSchemas.VERSION = 1` — أي تغيير ترتيب/حذف عمود يرفعه |

## §4 الملفات الأخرى (موجودة قبل v1 — موثقة هنا للاكتمال)

- **المصنف الشامل `superbiz-report-*.xlsx`** (ReportsScreen → `buildReportSheets`):
  5 أوراق ثابتة الترتيب: الملخص (البند/القيمة)، ميزان المراجعة (البند/مدين/دائن)،
  كبار العملاء، كبار المنتجات، أعمار الذمم (<30/30-60/60-90/>90).
- **الدفتر التفصيلي `deep-register-*.xlsx` + `deep-sales/purchases-*.csv`**
  (`DeepWorkbookP44`): 11 عموداً: رقم الفاتورة، التاريخ، الطرف، الصنف، الكمية،
  السعر، الخصم، الصافي، فئة الضريبة (S/Z/E)، النسبة %، الضريبة — المبالغ رقمية بالأساس.
- **النسخ الاحتياطي JSON** (مساراً: format 3 الكامل و`superbiz-backup` الدمجي):
  المبالغ **قروش Long صحيحة** (علم `"p8":true` يفسّر النسخ القديمة الريالية) —
  انظر `BackupKit.kt` و`BackupContractP36Test` لعقد 25 جدولاً.
- **XML الفاتورة القانوني** (`ZatcaInvoiceXml`): UBL-lite بعملة لقطة الفاتورة.
- **ملف الإعدادات JSON** (`SettingsCodec`): قائمة بيضاء صارمة بمفاتيح أنواع
  string/number/bool — بما فيها `taxJurisdiction` و`displayCurrency` منذ v1 من هذا العقد.

## §5 الأمان

1. التصدير عبر SAF حصراً (`CreateDocument`) — بلا أذونات تخزين في الـManifest.
2. لا خرج للنسخ الاحتياطي يحمل مادة تحقق (pin\*/biometric) — عقد R12-C11.
3. حرس حقن CSV موحّد (H-21) أعلاه — والاختبار `CsvKitTest` يحرس سلوكه.
4. عملة الفاتورة الأجنبية (H4-1/R17) لا تغيّر وحدات الملفات: **أعمدة المال دائماً قروش الأساس** (ADR-002 §1 [R17-5])، و«الفئة الأصلية» وثيقة عرض على الصف نفسه.
